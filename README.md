# Arz. — Pakistani Climate Awareness Platform

> **AI Seekho Assignment 4**: *"Solve a Real Problem in Pakistan with Next.js"*

**Arz.** is an interactive climate-awareness landing page designed specifically for Pakistan. It highlights the real human and economic costs of climate change using verified data from global and national institutions, outlines practical community solutions, and provides a real-time lead capture form for community participation backed by Supabase.

---

## 🌍 The Problem Statement & Verified Statistics

Pakistan contributes less than 1% of global greenhouse emissions, yet remains one of the most vulnerable nations to extreme weather events:

1. **33 Million Displaced & $15.2B Economic Losses** during the devastating 2022 monsoon floods.  
   *Source*: [World Bank Post-Disaster Needs Assessment (PDNA)](https://www.worldbank.org/en/news/press-release/2022/10/28/pakistan-flood-damages-and-economic-losses-over-usd-30-billion-and-reconstruction-needs-over-usd-16-billion-new-assessme)
2. **Up to 9% of GDP at Risk Annually** under worst-case warming scenarios due to agricultural disruption and infrastructure destruction.  
   *Source*: [US Congress Congressional Research Service (CRS) Report](https://www.congress.gov/crs-product/IF12211)
3. **Ranked 176 out of 180 on Climate Readiness**, indicating high vulnerability coupled with low adaptive infrastructure.  
   *Source*: [Britannica Summary & ND-GAIN Index](https://www.britannica.com/event/Pakistan-floods-of-2022)

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router) + TypeScript
- **Styling**: Tailwind CSS v4 + Custom Keyframe Animations
- **Database**: Supabase (`community_members` table)
- **Typography**: Google Fonts via `next/font/google` (`Space Grotesk`, `IBM Plex Mono`, `Inter`)
- **Graphics**: Original animated SVG "Cracked Earth" Globe with SVG glow filters, floating embers, and client-side scroll parallax

## 🚀 Quick Start & Local Setup

### 1. Clone the Repository
```bash
git clone https://github.com/mally-pk/arz-climate-pk.git
cd arz-climate-pk
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Environment Setup
Copy the example environment file:
```bash
cp .env.local.example .env.local
```

Open `.env.local` and add your Supabase credentials:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-supabase-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key-here
```

*(Note: If no Supabase environment variables are set, the app runs in local demo mode, gracefully validating form inputs and logging submissions to the server console).*

### 4. Database Setup (Supabase SQL Editor)
Run the following query in your Supabase SQL editor to create the `community_members` table:
```sql
CREATE TABLE community_members (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  email TEXT NOT NULL,
  city TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

ALTER TABLE community_members ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow public insert" ON community_members FOR INSERT WITH CHECK (true);
```

### 5. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📸 Core Features & Component Architecture

- **Navbar**: Glassmorphic header with smooth scroll navigation.
- **Hero & Globe**: Animated SVG cracked-earth illustration with rotating landmasses, drifting cloud layers, pulsing fault lines, and interactive count-up stat counters.
- **Danger Section**: 3D tilt cards detailing flood impact, glacial retreat, agricultural losses, and heatwaves.
- **Solutions Section**: 4 actionable climate mitigation paths for Pakistani communities (Urban Forestry, Rainwater Harvesting, Solar Microgrids, Resilient Agriculture).
- **Sources Section**: Proof-of-source list with clickable external links to verified reports.
- **Join Community**: Real lead-capture form with validation, async API submission, and inline user feedback.
